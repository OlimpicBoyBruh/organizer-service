# Органайзер учебных материалов

Приложение для организации учебных материалов с возможностью добавления дисциплин, материалов и прикрепления файлов.

## Особенности приложения

- Управление учебными дисциплинами (по умолчанию создается 5 дисциплин)
- Добавление материалов с тегами и датами
- Прикрепление файлов и ссылок к материалам
- Поиск и фильтрация материалов

## Требования

- Java 17 или выше
- Maven 3.6 или выше

## Как запустить приложение

### 1. Подготовка тестовых данных

Перед запуском приложения рекомендуется создать тестовые данные:

```
mvn exec:java
```

Эта команда запустит класс `CreateSampleDataApp`, который создаст:
- 5 учебных дисциплин: Программирование на Java, Базы данных, Алгоритмы и структуры данных, Компьютерные сети, Машинное обучение
- Тестовые PDF файлы для каждой дисциплины в директории `~/organizer_data/pdfs`

Также вы можете запустить создание тестовых данных через Spring Boot приложение:

```
mvn spring-boot:run -Dspring-boot.run.arguments="--generate-data=true"
```

### 2. Запуск приложения

Для запуска приложения выполните:

```
mvn spring-boot:run
```

Или с помощью JavaFX Maven плагина:

```
mvn javafx:run
```

## Руководство по использованию

1. **Просмотр дисциплин**: При запуске приложения в левой панели отображается список дисциплин.
2. **Просмотр материалов**: Выберите дисциплину, чтобы увидеть список материалов.
3. **Добавление материала**: Нажмите кнопку "Добавить материал", заполните форму и нажмите "Сохранить".
4. **Прикрепление файлов**: Выберите материал и нажмите кнопку "Прикрепить файл".
5. **Прикрепление ссылок**: Выберите материал и нажмите кнопку "Добавить ссылку".

## Примечания

- Все файлы сохраняются в директории `~/organizer_data/pdfs`
- Каждый материал может иметь несколько прикрепленных файлов и ссылок
- Используйте теги для удобного поиска и фильтрации материалов

## Возможные проблемы и решения

### Ошибка ClassNotFoundException или NoClassDefFoundError

Если вы видите ошибки связанные с отсутствием классов при запуске, используйте:

```
mvn clean install
mvn spring-boot:run
```

### Проблема с JavaFX

Если при запуске через `mvn javafx:run` возникают проблемы с JavaFX, используйте альтернативный способ запуска через Spring Boot:

```
mvn spring-boot:run
```
