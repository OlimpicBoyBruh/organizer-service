### Введение

Данное руководство предназначено для пользователей приложения-органайзера учебных материалов. Приложение позволяет организовывать учебные материалы по дисциплинам, прикреплять к ним файлы и ссылки, а также быстро находить нужную информацию.

### Установка и запуск

#### Системные требования
- Операционная система: Windows 10 или выше
- Установленная Java: версия 17 или выше
- Оперативная память: не менее 4 ГБ
- Свободное место на диске: не менее 100 МБ

#### Порядок установки
1. Скачайте JAR-файл приложения `organizer-app.jar` из репозитория
2. Разместите файл в любой удобной директории на вашем компьютере

#### Запуск приложения
Запустить приложение можно одним из следующих способов:
- Двойным щелчком по файлу `organizer-app.jar`
- Через командную строку:
  ```
  java -jar organizer-app.jar
  ```

### Главное окно приложения

После запуска приложения откроется главное окно, которое состоит из следующих основных областей:

1. **Панель дисциплин** (слева) - отображает древовидную структуру дисциплин
2. **Панель материалов** (в центре) - показывает список материалов выбранной дисциплины
3. **Панель деталей** (справа вверху) - отображает информацию о выбранном материале
4. **Панель вложений** (справа внизу) - показывает прикрепленные файлы и ссылки
5. **Панель поиска** (вверху) - позволяет искать материалы по различным критериям

### Работа с дисциплинами

#### Добавление новой дисциплины
1. В левой части окна найдите поле ввода под деревом дисциплин
2. Введите название новой дисциплины
3. Нажмите кнопку "Добавить"
4. Новая дисциплина появится в дереве дисциплин

#### Выбор дисциплины
1. В дереве дисциплин щелкните по названию нужной дисциплины
2. В центральной панели отобразятся материалы выбранной дисциплины

### Работа с материалами

#### Добавление нового материала
1. Выберите дисциплину в дереве дисциплин
2. Нажмите кнопку "Добавить новый материал" под списком материалов
3. В открывшемся диалоговом окне введите:
   - Название материала
   - Теги (через запятую)
4. Нажмите "ОК"
5. Новый материал появится в списке материалов выбранной дисциплины

#### Просмотр деталей материала
1. Выберите материал в списке материалов
2. В правой верхней панели отобразится подробная информация:
   - Название материала
   - Дата добавления
   - Теги
   - Дополнительные детали

### Работа с файлами и ссылками

#### Прикрепление файла к материалу
1. Выберите материал в списке материалов
2. Нажмите кнопку "Прикрепить файл" под списком вложений
3. В открывшемся диалоговом окне выберите файл на вашем компьютере
4. Нажмите "Открыть"
5. Выбранный файл будет скопирован в директорию приложения и добавлен в список вложений

#### Прикрепление ссылки
1. Выберите материал в списке материалов
2. Нажмите кнопку "Прикрепить ссылку" под списком вложений
3. В открывшемся диалоговом окне введите:
   - Название ссылки
   - URL (адрес ссылки)
4. Нажмите "ОК"
5. Ссылка будет добавлена в список вложений

#### Открытие прикрепленного файла или ссылки
1. Выберите материал в списке материалов
2. В нижней правой панели выберите файл или ссылку в списке вложений
3. Нажмите кнопку "Открыть"
4. Файл будет открыт в соответствующем приложении (например, PDF в программе для просмотра PDF)
5. Ссылка будет открыта в веб-браузере по умолчанию

#### Удаление вложения
1. Выберите материал в списке материалов
2. В списке вложений выберите файл или ссылку, которую хотите удалить
3. Нажмите кнопку "Удалить"
4. Подтвердите удаление в появившемся диалоговом окне

### Поиск материалов

#### Поиск по названию
1. В верхней панели введите часть названия материала в поле "Поиск по названию"
2. Нажмите кнопку "Поиск"
3. В списке материалов отобразятся только те, которые соответствуют запросу

#### Поиск по дате
1. В верхней панели введите дату в формате ДД.ММ.ГГГГ в поле "Поиск по дате"
2. Нажмите кнопку "Поиск"
3. В списке материалов отобразятся только те, которые были добавлены в указанную дату

#### Поиск по тегу
1. В верхней панели введите тег в поле "Поиск по тегу"
2. Нажмите кнопку "Поиск"
3. В списке материалов отобразятся только те, которые содержат указанный тег

#### Сброс результатов поиска
1. Очистите все поля поиска
2. Нажмите кнопку "Поиск"
3. Будут отображены все материалы выбранной дисциплины

### Устранение неполадок

#### Приложение не запускается
1. Убедитесь, что на вашем компьютере установлена Java 17 или выше
2. Проверьте, что у вас достаточно прав для запуска приложения
3. Попробуйте запустить приложение из командной строки для просмотра ошибок:
   ```
   java -jar organizer-app.jar
   ```

#### Невозможно открыть прикрепленный файл
1. Убедитесь, что на вашем компьютере установлено приложение для открытия данного типа файлов
2. Проверьте, что файл не поврежден
3. Попробуйте прикрепить файл заново

#### Проблемы с отображением кириллических символов
1. Убедитесь, что в настройках Java используется кодировка UTF-8
2. Попробуйте перезапустить приложение
